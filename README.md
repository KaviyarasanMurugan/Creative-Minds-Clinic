# Creative Minds Clinic — V7

Frontend-only clinic website for Creative Minds Clinic, Hoodi, Bengaluru.

## V7 refinements
- Removed the unnecessary “More specialists can be added easily” panel from the specialists section.
- Refined the Creative Minds Clinic brand lockup using the clinic logo's cyan, blue and lime colour language.
- Updated the header brand, hero clinic name and logo treatment for a more distinctive identity.
- Kept the specialist grid responsive so additional doctor cards can be added later without changing the layout structure.
- Preserved the colourful section system, therapy details, patient experiences, appointment flow, DMIT section, location preview, WhatsApp and privacy policy.

## Run locally
Open `index.html` in Chrome/Edge, or serve the folder with a local static server.
